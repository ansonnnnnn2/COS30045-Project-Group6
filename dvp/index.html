About & data notes

About VisiRoad

VisiRoad reads the supplied FinalG6.csv: 81,562 national records and 3,835 state/territory records. The plotted measure is Count of cases, not the previous Hospitalisations measure. National and state records describe overlapping populations and are analysed separately. These are counts, not exposure-adjusted risks.

The national overview, monthly comparison and Groups charts use the national rows. The Regional Map view also includes a state/territory bar chart from the same merged file. That state chart uses only total rows and responds only to Year; demographic and remoteness filters are not applied because the state tables do not contain joint combinations. National and state published totals are not forced to match or added together. Main Export CSV downloads the national selection; Export state totals downloads state total rows for the selected year.

The supplied KNIME rules converted suppressed n.p. values to zero. FinalG6.csv no longer distinguishes those substitutions from measured zeroes. State demographic sums can therefore understate the underlying totals. The website uses the uploaded file unchanged and does not treat its zeroes as evidence that the original suppressed values were known.

Understanding the map

Map boundaries: ABS ASGS 2021 Remoteness Areas. Regional merges Inner and Outer Regional; Remote merges Remote and Very Remote. The colours show categories, and their opacity changes with selected Australia-wide category totals. These are not counts at individual locations or polygons. The boundaries are fixed to the 2021 classification, even when viewing earlier years. “Not stated” has no mapped boundary. ABS remoteness geography.

Using the dashboard

Dataset-specific filters apply across the three views. Click a year or a category to select it; click again to clear it. Use Reset filters to return to all data. Export CSV downloads the currently filtered records.

The annual chart preserves all years and the monthly chart compares 2020 with the 2017–2019 average. Each group chart preserves its own category alternatives. The state comparison responds to Year only.
