About VisiRoad

VisiRoad currently uses CSVG6.csv cleaned hospitalised road-injury records from 2011–2021. To use the latest KNIME workflow output, export Final.csv and replace data/CSVG6.csv with a CSV using the expected column names. Figures are counts of hospitalisations, not rates per person or per kilometre travelled.
